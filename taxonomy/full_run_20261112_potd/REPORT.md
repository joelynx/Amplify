# Classification of the MODS Problem of the Day import (2026-11-12)

2,678 olympiad questions imported from the MODS POTD sheet on 2026-11-12, run through the 11-02 pipeline as olympiad sources: Sonnet first pass with the olympiad tag file, blind second opinion on every medium/low label (Haiku) and on every wastebasket or other-subject label (Sonnet), Opus adjudication of every disagreement (A/B order random). Trees regenerated from `taxonomy.json`. Candidate subjects come from the sheet's genre letters (A, C, G, N; CG = combinatorial geometry), with Probability for questions asking for a probability or expectation and Calculus / Linear Algebra for university contests and analysis wording; the curators' genre and tag went to the classifier as a hint. Most questions have no solution: the classifier saw the sheet's own hints instead where there were any.

## Outcome

- Placed in a subtopic: 2,675; left `Uncategorized`: 3 (`wastebasket.csv`).
- How the final label was reached: high-confidence first pass 850; first and second agree 989; second opinion accepted 12; Opus 827.
- Flags: {'mismatch': 2} (`flags.csv`).
