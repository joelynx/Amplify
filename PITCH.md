# Amplify — Faculty Pitch

**Practice STEM problems the way they should be practiced.**

A one-page pitch for an IIT-Delhi Abu Dhabi faculty member. Hand them this. Email them this. Print it.

---

## The problem

Every freshman at IIT-AD practices the same way: hunting for problem sets in a Dropbox folder, printing a PDF, writing answers in a notebook, and waiting until the TA session to find out if they were right. There is no instant feedback. There is no record of what they've practiced or where their gaps are. And the same 200 problems get circulated semester after semester because there is no shared place to put new ones.

Faculty have it worse. To set a new problem set, you copy-paste from last year's `.tex` file, swap a few numbers, hope nothing breaks, and run XeLaTeX three times to fix the alignment. Building a *new* question with a clean solution and a typeset diagram is a 30-minute task you do five times a week. There is no version control, no peer review, no sense of which questions actually teach the concept.

## What we're building

**Amplify** is a web application that:

1. **Renders any question instantly in the browser.** No PDFs, no LaTeX installs. Phone-friendly. Permalink per question.
2. **Tracks per-subtopic mastery for each student.** A student sees, in plain English: *"You've nailed limits but you're guessing on series convergence — try these 5."*
3. **Lets faculty author and curate questions with live LaTeX preview, peer review, and revision history.** Think Overleaf, but built for problem sets instead of papers.
4. **Generates problem sets and exam papers** in seconds, filtered by topic, branch, subtopic, difficulty, source, and tags. PDF export when you need it.
5. **Builds a shared, peer-reviewed bank of IIT-AD problems** that grows every semester instead of being lost in a Drive folder.

## What we want from you

We want to pilot Amplify in **one course this fall** — ideally MTL101 (Calculus) or another course you teach. Specifically:

- A read on whether the question types, taxonomy, and solution format match how you actually set problems.
- Permission to seed the bank with your existing problem-set archive (we type-set and tag it; you review).
- A nudge to your students to try it during the semester. No mandate — just a Moodle announcement.
